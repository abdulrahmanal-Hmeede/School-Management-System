# مشروع نظام إدارة المدرسة

هذا المشروع هو نظام لإدارة المدرسة يشمل إدارة الطلاب، المعلمين، المواد الدراسية، الدرجات والحضور.

## أعضاء الفريق

- عبدالرحمن الحميدي.
- عزالدين الظاهر.
- فيصل اطلي.
- محمد غنوم.
- محمد الشيخ.
## طريقة التشغيل

1. افتح الملف `index.html` في المتصفح.
2. استخدم الواجهة للتنقل بين الصفحات وإدارة البيانات.
